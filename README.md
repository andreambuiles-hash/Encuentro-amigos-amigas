# Encuentro de amigos y amigas
Aplicacion React + Supabase para listas de regalos compartidas y reservas anonimas.

## Publicar en Vercel
1. Descomprime el ZIP.
2. Sube la carpeta a un repositorio nuevo de GitHub.
3. En Vercel, pulsa Add New > Project e importa el repositorio.
4. Vercel detectara Vite. Pulsa Deploy.
5. Abre el enlace publico y prueba agregar, reservar y liberar un regalo.
